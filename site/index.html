機能

ローカルLLM連携

Apple M5チップ搭載Mac上でQwen3.6やNemotronなどのローカルLLMと連携し、クラウド不要で動作します。

4つのツール

bash, read_file, write_file, edit_fileの4つのツールのみで、ファイルの作成・編集・実行・検証を完結します。

完全ローカル

依存はlibcurlとcJSONのみ。外部APIやクラウドサービスに一切依存せず、完全にローカルで動作します。

使い方 

# 1. ビルド
make

# 2. 対話モード
./agent

# 3. ワンショット実行
./agent -y -p "タスク"

# 4. モデル切替
AGENT_MODEL=mlx5/Qwen3.4 ./agent

依存ライブラリ: libcurl (HTTP/HTTPS通信), cJSON (JSONパース)
